# Guide du Développeur - Elhiann

Un guide interactif et moderne réunissant en un seul endroit toutes les ressources essentielles pour apprendre le développement web.

## Description

Ce projet est un guide complet destiné aux aspirants développeurs. Il couvre :

- **Bonnes pratiques** pour apprendre efficacement
- **Soft Skills** essentielles pour les développeurs
- **Git & GitHub** - l'outil indispensable
- **Timeline Front-End** - HTML, CSS, JavaScript, React
- **Timeline Back-End** - Node.js, Express, APIs REST
- **Compétences Bonus** - DevOps, Design, Cybersécurité, IA

## Technologies utilisées

- **Vite** - Build tool ultra-rapide
- **React** - Bibliothèque UI
- **TypeScript** - Typage statique
- **Tailwind CSS** - Styling utilitaire
- **shadcn/ui** - Composants UI modernes

## Installation

La seule exigence est d'avoir Node.js et npm installés - [installer avec nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

```sh
# Étape 1 : Cloner le dépôt
git clone https://github.com/Elhians/elhiann-guide-dev.git

# Étape 2 : Accéder au répertoire du projet
cd elhiann-guide-dev

# Étape 3 : Installer les dépendances
npm install

# Étape 4 : Lancer le serveur de développement
npm run dev
```

## Déploiement

Le projet peut être déployé sur Vercel, Netlify ou toute autre plateforme supportant les applications Vite/React.
